- **[`docs/prd/`](docs/prd/)** — PRDs (Product Requirements Documents): el *qué* y el *por qué* de cada feature. / The *what* and *why* of each feature.
- **[`openspec/`](openspec/)** — Specs y propuestas de cambio: el *cómo*. / Specs and change proposals: the *how*.
