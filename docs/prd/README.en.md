# PRDs

[Español](README.md) · **English**

This directory holds the project's PRDs (Product Requirements Documents). Each PRD describes a product capability — the *what* and *why*. OpenSpec specs (in [`../../openspec/`](../../openspec/)) translate PRDs into the *how*, and code implements the specs.

## Conventions

- One file per PRD, kebab-case: `<feature>.md` (e.g. `route-schedule-feed.md`).
- PRDs are written in Spanish; if an English version is needed, add `<feature>.en.md` next to it.
- Read the motivating PRD before drafting a spec.
